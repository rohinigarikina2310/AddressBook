# Address Book Management system

# 1.Project Description
The Address Book Management System is a C programming project designed to store and manage contact information.
it provides a structured way to maintain contact details using C programming concepts.

# 2.Features
1.create contacts
2.Search contacts
3.edit contact details
4.Delete contacts
5.list all contacts
6.store and manage contact information using file handling

# 3.Technologies Used
1. C programming
2. Structures
3. Pointers
4. File Handling
5. Functions

# 4.Project Files
1. `main.c`-Main function
2. `contact.c`-Contact related operations
3. `contact.h`-Contact-header file
4. `file.c`-File handling Operations
5. `file.h`-File handling header file

## 5.How to Compile and Run
### compile
`gcc main.c contact.c file.c -o AddressBook`
# Run on Windows
.\AddressBook.exe
# Run on linux
./AddressBook

# 6.Requirements
1.GCC compiler
2.Visual Studio code(optional)
